# 0.91.1 发布摘要

本版发布当前本地创作工作台，补齐他人从仓库安装运行的依赖闭包。前端版本、Python 服务、129 个工作流执行模板以及百度 SD2 / SD2.5 的接入代码一并发布；用户凭据、个人素材、任务数据库和历史审查产物不进入仓库。

## 变化

- 原生 Python 的本机回环访问默认直接进入工作区；连接失败显示重新连接，不出现不适用的登录表单。外部访问与 Railway 保持账户、CSRF 和资源归属校验。
- 自由创作首尾帧分别提供导入、素材库、替换和移除；导入期间切换创作不会覆盖新草稿。缩略图完整显示，不遮挡按钮。
- 修复取消/提交竞态、路由与历史恢复、搜索初始化、工作流参数交互及来源校验问题。
- 百度 SD2 / SD2.5 有独立客户端、创建/查询/保存/恢复代码，修复本地人民币报价接口被错误禁用的问题。费用变化与重复提交仍在服务端校验。
- 干净仓库审查修复 10 个模板：恢复 5 个旧模板缺少的 6 处固定执行协议，以及 5 个自动定位模板的通用默认词 `human` / `cloths`。导出规则按工作流与节点精确保留通用默认，不恢复个人示例或旧结果缓存。模板和计价计划引用的哈希同步更新，93 条价格、6 个套餐与计价来源保持不变。
- Compose 传入百度 API key，并明确使用账户模式，使经网桥的浏览器访问和容器诊断行为一致。免登录本地体验使用原生 Python 入口。
- 提供 [本地部署指南](local-deployment.md)、离线安装检查与回归测试；前端不需构建，默认运行不依赖作者电脑目录。

## 工作流与 API 的数量

公开 manifest 注册 **129 个模板：127 个卡端工作流，加 H3 与 Bernini 两个命名模板**。执行由 34 个既有适配器与 95 个通用合同完成。两个百度视频 API 单独计数。6 个 blocked 工作流仍保留真实状态；151 个目录界面不能视作 151 个已验收生成服务。

所有模板可从公开文件构造，不依赖作者的私有编译图。运行时仍需自己的 ComfyUI 模型、自定义节点、平台节点权限，以及适用的 API 凭据/额度。未接入的自由创作模型继续禁用真实生成；首尾帧界面不扩大百度接口的支持范围。

## 验证与边界

发布前使用独立 Python 3.12 环境从 `requirements-dev.txt` 安装依赖，使用只含待发布文件的副本检查资源、启动服务和执行回归。前端测试不依赖私有素材；工作流固定协议包含输入值真实流到最终节点的语义回归；两百度客户端通过模拟 HTTP 验证 payload、认证、状态与错误处理，不发送真实付费请求。

CI 在 Windows / Linux 检查后端、前端和模板，并在 Linux 构建容器、检查账户边界、抠图和成片音画循环。历史原生节点快照的比较仅在维护者提供对应证据时额外运行，不随仓库发布私有快照。

这些检查不等于所有模型在另一台算力机器上完成真实生成。新部署需按自己的目标工作流做实际输入、输出与恢复验收；供应商凭据是否有效、是否有额度以及输出质量不能由离线合同测试证明。

## 升级

更新源码或镜像，保留自己的 `.env` 与数据卷。不要覆盖原账户数据库、素材、任务和账本，也不要将它们提交 Git。新部署按 [本地部署指南](local-deployment.md) 配置；现有 Railway 部署保留账户模式、单进程和持久卷。部署版本以 `/version.json` 为准。
