# 0.91.2 工作流封面补齐

将本地正在使用、可正常加载的历史封面导出为随仓库发布的示例素材。14 个工作流共用 20 个 WebP 图片文件，约 1.48 MB；4 个类别有对应的封面映射。原有其他工作流的用途示意封面继续保留。

公开图片位于 `public/assets/workflow-covers/`，按内容去重、适配封面尺寸，并清除提示词、工作流、EXIF、位置与路径等附加元数据。GIF 示例保留原动画帧和播放时序。清单 `public/workflow-cover-media.js` 仅包含相对静态路径，不发布任务数据库、原始素材目录或本机服务地址。

封面顺序为：使用者自己的有效历史作品、随仓库发布的示例、原有用途示意图片、纯图示。发布封面使用“示例”标识，保留原图与结果的配对、类别语义与现有布局。图片加载失败逐级回退，不重复请求同一失效来源。

新克隆、Docker 和 GitHub Pages 都可直接显示封面；无需导入作者的浏览器历史。此前已失效的本地历史图片没有恢复或冒充有效封面。工作流节点、参数、真实连接和 API 行为沿用 [0.91.1](release-0.91.1.md)，部署步骤见 [本地部署指南](local-deployment.md)。
