# 账号、权限与积分操作

## 首次管理员与原有数据

首次启动会在服务端 `private/admin-bootstrap.json` 生成本机管理员凭据。只在本机打开该文件获取登录信息，不要上传或公开。登录后点击侧栏底部账号按钮，在菜单进入“我的账号 → 账号安全”修改密码，再重新登录。密码修改会注销原有会话。

原有任务和素材一次性归初始管理员，原文件与任务内容保留。初始管理员在原浏览器登录时，会一次性复制该浏览器原有草稿和素材记录到自己的账号存储；普通新账号不继承这些记录。草稿及浏览器素材保存在当前浏览器，不等于跨设备同步。

## 账号与权限

- 注册获得普通用户权限，不会自动成为管理员。点击侧栏用户名进入“我的账号”，查看余额、充值订单和积分记录。
- 作品、任务、素材接口按账号归属校验；相同文件可共用内容存储，但素材名称、原图关系和标注方式按账号隔离。切换账号后页面重新载入，浏览器草稿也切换到该账号的存储。
- 账号菜单集中提供我的账号、积分充值、偏好设置、退出登录；管理员另有“管理员后台”。后台是独立的 `admin.html` 页面，不再放在创作台侧栏。旧 `studio.html#admin` 链接会进入独立后台。
- 管理员在“用户管理”中按用户名、权限和状态搜索，使用分页浏览；打开账号管理面板修改角色、停用/恢复或查看账本。不能停用或降级唯一可用管理员。停用账号会注销该账号会话。账户管理权限不取消作品与素材的归属校验。
- “新增用户”在右侧打开表单，填写用户名、初始密码及确认密码，默认普通用户；也可选择管理员。新账号的可用和冻结积分均为 0，创建后可单独调整积分。创建不会切换当前登录；关闭窗口清除密码。创建成功后定位新账号，点“返回原筛选”恢复原查询。

## 管理员调整积分

在“用户管理”对应行点击“调整积分”，选择增加或扣减，填写整数数量与至少三个字符的理由，再核对修改前后余额并保存。调整只改变可用积分，冻结积分保持不变，不能扣成负数；给停用账号调整积分也不会恢复其使用权限。

余额变化、账本与管理员操作记录一并保存。相同请求重试只记一次；参数改变后视为新的调整。响应丢失时可用原表单重试核对同一笔操作，不自动换成新请求。管理员可在账号面板查看账本，在“操作记录”查看调整原因和操作者。普通账号不能直接调用调整接口。

## 配置套餐与创作费用

1. 管理员在“管理员后台 → 套餐与计价”新增或编辑套餐，填写名称、积分及人民币金额，并决定是否允许购买。本平台基础兑换为 1 元 = 100 积分。本轮配置六档一次性充值：50 / 75 / 150 / 225 / 450 / 900 元，分别 5,000 / 7,500 / 15,000 / 22,500 / 45,000 / 90,000 积分。
2. 同页按工具名称查找、按已配置/未配置筛选，并设置每次任务的整数积分，每页 20 项。可以明确设置为 `0`；未配置费用的工具禁止真实提交。已接入工作流的初始报价来自当前图兼容历史的中位执行耗时：60 秒 = 10 积分，按比例向上取整到 1 积分；没有可靠记录的条目保持原价。
3. 用户真实提交前在生成按钮看到当前积分报价。费用发生变化时需重新确认；重复发送同一提交编号及相同参数不会重复创建任务或扣费。自由创作按钮统一为“生成”，显示公开费率估算的积分；当前四款模型尚未接入真实生成服务，按钮暂不可提交，保留描述与素材，不再返回预置素材作为生成结果。费用配置与服务接入分别核对，前者不代表已经可生成。公开参考费率见 `public/pricing-policy.json`，本次部署检查见 [发布审查](workflow-release-review-2026-10-07.md)。

0.81.1 首次启动会校验脱敏发布计划与实际执行模板，先在私有数据目录备份，再在同一事务补入缺失的 93 个工作流报价与 6 个套餐。沿用本机既有初始化标记：已经初始化的环境不重复写入，现存管理员改价优先，后续启动也不回填人工删除的条目。36 个没有可靠历史耗时的已接入工具不新增价格。原始耗时记录仅保留在本机，不随公开仓库发布。

| 积分状态 | 行为 |
| --- | --- |
| 可用 | 可用于提交新任务的余额；不足时拒绝提交。 |
| 冻结 | 保存任务时原子预扣，等待任务结果；不是第二次扣费。 |
| 结算 | 任务成功后结束冻结，确认这次消耗。 |
| 释放 | 确认失败或取消后退回预扣，恢复可用余额。 |

状态不确定、停止本地等待、或作品取回失败会保留冻结，避免远端已消耗却自动退积分。管理员在“账务核对 → 创作积分”先核对算力卡任务和实际消耗，再填写核对凭证与说明，选择结算或退回。正常排队、运行中的任务不能从该入口处理；已处理记录不能反向改账。退回平台积分不表示外部算力退款或停止远端任务。

## 充值到账与异常核对

用户进入“积分充值”选择已启用套餐和渠道，创建订单。套餐金额与积分由服务端冻结，不接受浏览器自报金额到账。

- **银行卡、联系管理员**：按收款说明操作。管理员核对实际收款、订单金额及唯一付款凭证后，在订单列表确认到账；创建订单或点击“已付款”不增加积分。
- **已配置的支付宝、微信**：服务端请求渠道前先保存收款标记；只有支付通知验签、身份及金额核对通过后才到账。跳转成功、二维码展示或付款截图不能直接入账。已发起自动收款的订单禁止再走人工确认；超时应使用原订单核对或重试。
- **迟到或冲突通知**：保留已验签收款证据，进入“待核对的支付异常”。管理员可核实后补记积分，或填写已经实际完成的线下退款凭证。记录退款不执行自动退款；已经到账的交易不能仅记退款而不办理积分冲正。

重复确认及重复支付通知不会重复入账。查看账号页面的订单状态与积分记录确认结果；凭证、结算及人工处理保留审计记录。

渠道凭据、银行卡说明、公网通知地址及上线实测要求见 [充值渠道配置](payment-configuration.md)。配置不完整的渠道关闭；没有启用套餐时不能购买。
